# Research Synthesis — Experiment E3 (Throughput & Duration Analysis)

## 1. Context & Purpose

Experiment **E3** analyzed real Internet behavior during variable-duration download throughput tests.

## 2. Empirical Findings

1. **Early Completion vs Duration Limits**:
   - High-throughput links often transfer scheduled test payloads before reaching the maximum time window (e.g. 10s cutoff).
   - Constrained or high-latency links reach the duration limit while payload transfer is still in progress.
2. **Variable Data Volumes**:
   - Tests do not transfer a static number of bytes. The total bytes transferred varies per test based on window scaling and link speed.

## 3. Production Rules Enforced in IPMCAS Engine

1. **Dual Status Classification**:
   - Tests finishing payload queues before duration limit are tagged as `COMPLETED`.
   - Tests hitting the time cutoff are tagged as `DURATION_LIMIT_REACHED`.
   - In both cases, throughput calculation uses the **exact active transfer duration** ($\Delta t$), preventing artificial velocity underestimation:
   $$\text{Throughput} = \frac{\text{Bytes Transferred} \times 8}{\text{Active Duration (seconds)} \times 10^6} \quad (\text{Mbps})$$
2. **Warmup Phase Filter**:
   - Exclude initial 500ms of TCP slow-start from average throughput calculation to reflect sustained capacity accurately.
