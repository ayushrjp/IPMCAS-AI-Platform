# Research Synthesis — Experiment E2 (Baseline / Target Setup)

## 1. Context & Purpose

Experiment **E2** evaluated baseline target Internet performance measurement parameters across control targets and edge nodes.

## 2. Key Methodological Lessons Applied to IPMCAS

1. **Target Ping & RTT Calibration**: Baseline latency sampling requires multiple consecutive probe samples (min 10 probes) to filter out initial TCP handshake SYN/ACK outliers.
2. **Jitter Calculation Standard**: Jitter must be computed using RFC 3550 mean absolute difference:
   $$J(i) = J(i-1) + \frac{|D(i-1, i)| - J(i-1)}{16}$$
   where $D(i-1, i)$ is the difference in transit time for adjacent probes.
3. **Control Target Selection**: A single target endpoint is insufficient due to routing variances. IPMCAS selects server nodes dynamically based on initial RTT probe ranking.
